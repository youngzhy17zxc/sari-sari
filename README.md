# 🏪 Sari-Sari Store POS System

A full-featured Point of Sale system for sari-sari stores with web, CLI, and GUI interfaces.

## 🚀 Features

- **Web Interface** - Customer-facing product browsing with real-time stock
- **CLI Tool** - Admin and cashier operations via terminal
- **GUI Application** - Tkinter-based desktop interface
- **Complete Backend** - Flask REST API with SQLite database
- **Inventory Management** - Add, update, delete products
- **Sales Processing** - Cash and GCash payments with receipts
- **Reporting** - Daily, monthly, and inventory reports
